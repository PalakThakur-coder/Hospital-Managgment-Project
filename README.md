# 🏥 Hospital Management System

A web-based Hospital Management System developed to manage IPD/OPD patient records, billing, and prescriptions efficiently.

## 🚀 Features
- Unique Patient ID generation with slip creation
- Add, Edit, Search Patient by ID or Name
- IPD/OPD Billing with Billing Number
- Update Bills and Tests
- Doctor can view patient details and give prescriptions
- Role-Based Login System:
  - Admin
  - Doctor
  - Representative

## 🛠️ Tech Stack
- Frontend: JSP, CSS, JavaScript, Bootstrap
- Backend: Java Servlets
- Database: MySQL
- Server: Apache Tomcat

## ⚙️ Setup Instructions

1. Import project into Eclipse IDE.
2. Configure Apache Tomcat Server.
3. Create a new database in MySQL.
4. Import the `hospital_db.sql` file.
5. Run the project on Tomcat Server.
